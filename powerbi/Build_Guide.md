# NovaMart Power BI Build Guide

## Project
**NovaMart Retail Performance Dashboard**

This is a fictional portfolio project using synthetic data. It is designed to demonstrate Power Query, data modeling, DAX, KPI reporting and interactive Power BI dashboards.

## 1. Load data
In Power BI Desktop: **Home → Get Data → Text/CSV** and load:
- customers.csv
- products.csv
- orders.csv
- order_items.csv
- payments.csv

Rename `order_items` to **Sales**.

## 2. Power Query cleaning
For each query:
- Set IDs to Text.
- Set OrderDate/PaymentDate to Date.
- Set Quantity to Whole Number.
- Set UnitPrice, CostPerUnit and PaymentAmount to Decimal Number.
- Set DiscountPct to Decimal Number.
- Trim/Clean text columns.
- Check duplicates in CustomerID, ProductID, OrderID and PaymentID.
- Check for blanks and invalid negative numeric values.
- Click **Close & Apply**.

## 3. Relationships
Create:
- Customers[CustomerID] 1 → * Sales[CustomerID]
- Products[ProductID] 1 → * Sales[ProductID]
- Date[Date] 1 → * Sales[OrderDate]
- Date[Date] 1 → * Payments[PaymentDate]
- Sales[OrderID] 1 → * Payments[OrderID]

Use single-direction filtering from dimensions to facts.

## 4. Date table
Create the Date table from `powerbi/DAX_Measures.md`, mark it as a Date table, and sort Month by Month Number.

## 5. DAX
Create all measures from `DAX_Measures.md`.

## 6. Dashboard pages
### Page 1 — Executive Overview
KPI cards: Revenue, Orders, Customers, AOV, Gross Profit, Profit Margin.
Charts: Monthly Revenue, Revenue by Category, Revenue by Region, Revenue by Channel.
Slicers: Date, Region, Category, Channel, Customer Segment.

### Page 2 — Product & Category Analysis
Revenue by Product, Units by Product, Gross Profit by Category, Top Products table, conditional formatting.

### Page 3 — Customer & Regional Analysis
Revenue by City, Revenue by Customer Segment, Top Customers, Orders by Region, AOV by Region.

### Page 4 — Operations & Data Quality
Completed/Cancelled/Returned Orders, Cancellation Rate, Payment Variance, Payment Method distribution, payment mismatch table.

## 7. Interactivity
Add slicers, cross-filtering, date drill-down, drill-through, report-page tooltips and conditional formatting. Bookmarks/page-navigation buttons are optional.

## 8. Save
Save the finished Power BI report as:
`NovaMart_Retail_Performance_Dashboard.pbix`

The PBIX must be created in Power BI Desktop; it is not generated by this ZIP.
