# \# NovaMart Retail Performance Dashboard

# 

# \## Overview

# 

# NovaMart Retail Performance Dashboard is an interactive Power BI project built using synthetic retail data to analyze sales performance, customer behavior, product performance, profitability, and operational metrics.

# 

# The dashboard provides business-focused insights through interactive KPIs, charts, slicers, and data-quality analysis.

# 

# \## Dashboard Pages

# 

# \### 1. Executive Overview

# \- Total Revenue

# \- Total Orders

# \- Total Customers

# \- Average Order Value

# \- Gross Profit

# \- Profit Margin

# \- Monthly revenue trends

# \- Revenue by category, region, and sales channel

# 

# \### 2. Product \& Category Analysis

# \- Revenue by product

# \- Units sold by product

# \- Revenue by category

# \- Gross profit by category

# \- Interactive category filtering

# 

# \### 3. Operations \& Data Quality

# \- Orders by status

# \- Cancelled and returned orders

# \- Cancellation rate

# \- Payment amount by payment method

# \- Payment transaction details

# 

# \## Tools \& Technologies

# 

# \- Power BI

# \- Power Query

# \- DAX

# \- Data Modeling

# \- Data Transformation

# \- Data Visualization

# \- KPI Reporting

# \- Data Validation
